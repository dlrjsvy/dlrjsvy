# 마음자리 프로토타입

지역·이용 자격·예산에 맞는 상담센터를 탐색하는 모바일 웹 프로토타입입니다.

## 폴더 구조

- `index.html` — 화면 마크업
- `css/style.css` — 전체 디자인
- `js/app.js` — 화면 이동, 검색, 저장 기능

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버로 실행합니다.

## 주요 기능

- 홈 · 검색 · 마이페이지 하단 내비게이션
- 조건별 센터 검색 및 상세 정보
- 센터 저장
- 프로필 정보 브라우저 저장

> 프로토타입 데이터이며 의료 진단을 제공하지 않습니다.
