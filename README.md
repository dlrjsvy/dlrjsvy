# 마음자리 프로토타입 0.4

경기도 31개 시·군의 정신건강복지센터와 청소년·청년 치료비 지원 정보를 찾는 모바일 웹 프로토타입입니다.

## 실행

저장소 루트의 `index.html`을 열면 **프로토타이핑 0.4 · 경기도**가 실행됩니다.

- GitHub Pages: 저장소의 Pages를 활성화하면 루트 화면으로 실행할 수 있습니다.
- 로컬 실행: `index.html`을 브라우저에서 직접 열 수 있습니다.
