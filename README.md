# 마음자리 프로토타입

경기도 31개 시·군의 정신건강복지센터와 청소년·청년 치료비 지원 정보를 찾는 모바일 웹 프로토타입입니다.

- 실행 버전: `v0.4`
- 문서 버전: `v0.4`
- 최종 수정일: `2026-11-17`
- 제품 요구사항: README 하단의 `제품 요구사항(PRD)` 섹션

## 실행

저장소 루트의 `index.html`을 열면 **프로토타이핑 0.4 · 경기도**가 실행됩니다.

- GitHub Pages: 저장소에서 Pages를 활성화하면 루트 화면을 실행할 수 있습니다.
- 로컬 실행: `index.html`을 브라우저에서 직접 엽니다.

## 주요 구성

- 경기도 31개 시·군 정신건강복지센터 31곳
- 2026 경기도 청소년·청년마인드케어 1건
- 긴급상담 자원 3건
- 로그인·회원가입·둘러보기 흐름
- 지역·지원 종류·대상 검색
- 센터·지원사업 상세 정보와 공식 출처
- 마이페이지, 관심 조건, 저장 기관, 최근 본 정보

## 버전 관리

이 프로젝트는 `주버전.부버전` 형식의 두 자리 버전을 사용합니다.

- 주버전: 호환되지 않는 큰 구조 변경
- 부버전: 기능 추가, 오류 수정 및 문서 보완
- 변경 이력은 항상 최신 버전을 위에 기록합니다.
- 실행물과 문서 버전이 다르면 README 상단에 각각 명시합니다.

### 제품 개요

마음자리는 경기도민이 지역 정신건강복지센터와 청소년·청년 치료비 지원 정보를 모바일 환경에서 빠르게 찾도록 돕는 웹 프로토타입입니다.

### 문제 정의

- 지역별 정신건강 지원기관 정보가 여러 공식 채널에 흩어져 있습니다.
- 이용자는 자신의 지역, 지원 유형, 대상 조건에 맞는 정보를 빠르게 비교하기 어렵습니다.
- 운영시간, 비용, 접수 가능 여부는 변동될 수 있어 공식 출처와 재확인 안내가 필요합니다.

### 목표

- 경기도 31개 시·군의 대표 정신건강복지센터를 한 화면에서 검색할 수 있게 합니다.
- 청소년·청년 치료비 지원사업의 핵심 조건과 신청 경로를 제공합니다.
- 긴급 상황에서는 일반 검색보다 긴급상담 연락처를 우선 안내합니다.
- 기관 정보마다 공식 출처와 확인일을 제공해 정보 신뢰성을 높입니다.

### 대상 사용자

- 정신건강 상담기관을 찾는 경기도민
- 청소년·청년 치료비 지원 정보를 찾는 이용자와 보호자
- 지역별 지원기관 정보를 안내하는 실무자

### 핵심 기능 요구사항

| ID | 기능 | 요구사항 |
|---|---|---|
| `FR-01` | 시작 흐름 | 로그인, 회원가입, 둘러보기 중 하나로 서비스에 진입할 수 있어야 합니다. |
| `FR-02` | 기관 검색 | 지역, 지원 종류, 이용 대상을 기준으로 결과를 필터링할 수 있어야 합니다. |
| `FR-03` | 상세 정보 | 기관명, 주소, 전화번호, 서비스, 이용 조건, 비용, 공식 출처를 표시해야 합니다. |
| `FR-04` | 지원사업 | 2026 경기도 청소년·청년마인드케어의 대상, 지원 범위, 신청 방법을 안내해야 합니다. |
| `FR-05` | 긴급상담 | 109, 1577-0199 및 경기도 위기대응 연락처를 눈에 띄게 제공해야 합니다. |
| `FR-06` | 마이페이지 | 관심 조건, 저장 기관, 최근 본 정보를 로컬 환경에 저장하고 표시해야 합니다. |
| `FR-07` | 출처 표시 | 주요 정보에 공식 출처와 확인일을 표시해야 합니다. |

### 데이터 요구사항

- 경기도 31개 시·군별 대표 정신건강복지센터 31곳을 포함합니다.
- 도 단위 청소년·청년 치료비 지원사업 1건을 포함합니다.
- 긴급상담 자원 3건을 포함합니다.
- 데이터 버전과 검증일을 기록합니다.
- 확인되지 않은 운영시간, 비용, 접수 상태는 추정하지 않고 기관 확인이 필요하다고 표시합니다.

### 비기능 요구사항

- 모바일 우선 화면으로 제공하며 주요 기능은 440px 이하 화면에서도 사용할 수 있어야 합니다.
- 정적 파일만으로 실행할 수 있어야 합니다.
- 주요 버튼과 입력 요소에는 명확한 텍스트와 접근 가능한 레이블을 제공합니다.
- 의료 진단을 제공하지 않는다는 고지와 긴급상황 우선 안내를 유지합니다.

### 범위 제외

- 의료 진단 또는 치료 권고
- 기관의 실시간 예약·접수 상태 보장
- 서버 기반 계정, 동기화, 결제 기능
- 경기도 외 지역의 기관 정보

### 완료 기준

- 경기도 31개 시·군 선택지가 검색 화면에 표시됩니다.
- 조건에 맞는 기관 결과와 상세 정보가 정상적으로 표시됩니다.
- 관심 조건, 저장 기관, 최근 본 정보가 브라우저 로컬 저장소에서 유지됩니다.
- 긴급상담 연락처를 누르면 전화 연결을 시도할 수 있습니다.
- README와 PRD의 버전 및 변경 이력이 최신순으로 일치합니다.

### PRD 버전 관리 규칙

- PRD 버전은 `주버전.부버전` 형식을 사용합니다.
- 요구사항의 큰 방향이 바뀌면 주버전을 올립니다.
- 기능 요구사항을 추가하거나 범위를 조정하면 부버전을 올립니다.
- 같은 버전의 문구 수정, 명확화, 오류 정정은 최종 수정일과 변경 내용으로 기록합니다.
- 새 개정 항목은 개정 이력 표의 맨 위에 추가합니다.
- PRD를 변경할 때 README 상단의 현재 문서 버전과 변경 이력도 함께 갱신합니다.

- 확인되지 않은 운영시간, 비용, 접수 상태는 추정하지 않고 기관 확인이 필요하다고 표시합니다.

### 비기능 요구사항

- 모바일 우선 화면으로 제공하며 주요 기능은 440px 이하 화면에서도 사용할 수 있어야 합니다.
- 정적 파일만으로 실행할 수 있어야 합니다.
- 주요 버튼과 입력 요소에는 명확한 텍스트와 접근 가능한 레이블을 제공합니다.
- 의료 진단을 제공하지 않는다는 고지와 긴급상황 우선 안내를 유지합니다.

### 범위 제외

- 의료 진단 또는 치료 권고
- 기관의 실시간 예약·접수 상태 보장
- 서버 기반 계정, 동기화, 결제 기능
- 경기도 외 지역의 기관 정보

### 완료 기준

- 경기도 31개 시·군 선택지가 검색 화면에 표시됩니다.
- 조건에 맞는 기관 결과와 상세 정보가 정상적으로 표시됩니다.
- 관심 조건, 저장 기관, 최근 본 정보가 브라우저 로컬 저장소에서 유지됩니다.
- 긴급상담 연락처를 누르면 전화 연결을 시도할 수 있습니다.
- README와 PRD의 버전 및 변경 이력이 최신순으로 일치합니다.

### PRD 버전 관리 규칙

- PRD 버전은 `주버전.부버전` 형식을 사용합니다.
- 요구사항의 큰 방향이 바뀌면 주버전을 올립니다.
- 기능 요구사항을 추가하거나 범위를 조정하면 부버전을 올립니다.
- 같은 버전의 문구 수정, 명확화, 오류 정정은 최종 수정일과 변경 내용으로 기록합니다.
- 새 개정 항목은 개정 이력 표의 맨 위에 추가합니다.
- PRD를 변경할 때 README의 현재 문서 버전과 변경 이력도 함께 갱신합니다.
